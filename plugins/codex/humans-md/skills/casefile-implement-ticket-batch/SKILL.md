# Casefile Implement Ticket Batch

Require the accepted plan and its exact matrix. Validate every binding, capability, ownership boundary, and review stage before delegation; ask the human rather than inventing missing values.

The root owns scope, dependency order, exclusive write ownership, acceptance, correction routing, and synthesis. Instantiate only declared workers. Assign overlapping mutations to one batch writer; all others remain read-only unless the matrix grants disjoint paths.

The writer returns immutable commits and focused evidence. Apply every recorded review stage to each ticket and correction. Focused verification checks acceptance and primary findings instead of repeating the review. Corrections return to the same writer in dependency order. Complete a ticket only after the recorded flow accepts it.
