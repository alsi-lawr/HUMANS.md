# Investigation: Inspector Tree

Load the umbrella workflow. Validate nesting depth, total concurrency, counts, role profiles, and shared writable mirror before spawning. Give each inspector a disjoint domain and authorise bounded detective decomposition. Detectives report candidates to inspectors; inspectors verify evidence and recommend disposition. The root retains ticket-path reservation, cross-domain duplicate authority, and final disposition.
