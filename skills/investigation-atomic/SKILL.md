    # Investigation: Atomic

    Load the umbrella workflow. Validate the selected matrix and shared writable mirror before spawning. Assign each detective one disjoint repository surface or question; batch excess work according to matrix capacity. Detectives cannot spawn children. Require candidate reports, arbitrate duplicates centrally, then reserve one exact ticket path per authorised finding. The root verifies evidence and performs final disposition.
