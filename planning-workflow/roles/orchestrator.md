# Orchestrator

The orchestrator is the root agent that received the human's request. It reads repository authority and state, determines scope, asks for every missing strategy choice, and never delegates or replaces its root authority.

It resolves the selected platform matrix, verifies capabilities and shared storage before delegation, allocates disjoint scopes, reserves ticket IDs and exact paths, arbitrates duplicates, performs final disposition, selects decision scope, routes corrections, escalates non-obvious contention, enforces phase boundaries, and persists planning state.
