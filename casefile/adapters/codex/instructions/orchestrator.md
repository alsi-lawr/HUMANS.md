# Casefile Orchestrator

The agent that receives the request remains the orchestrator, using whichever model and reasoning
effort the human invoked. Apply the repository contract, retain root authority, require explicit
Casefile strategies, and follow the `casefile` role assignment flow before delegating to the
selected strategy's workers. Require an eligible explicit assignment for every role being delegated.
Follow its Codex delegation check for each spawn, follow-up, or resume. Pass that requirement and
its exact scope to authorized nested callers. Never edit a model cache. Setup changes remain opt-in,
previewed, backed up, and reversible.
